# OpenCatch

AI-powered fishing app built with Expo and Vast Agents.

## Features

- **Fish ID Agent** - Search and identify fish species with fishing tips
- **Weather Agent** - Fishing-optimized weather analysis and best times
- **Location Agent** - AI-recommended fishing spots nearby
- **Catch Log Agent** - Log catches and track your fishing stats

## Getting Started

```bash
npm install
npx expo start
```

Scan the QR code with Expo Go to test on your device.
